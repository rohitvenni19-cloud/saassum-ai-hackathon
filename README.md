# 🚀 SaaSsum AI — Smart Spreadsheet Cleaner

**AI-Powered Excel & CSV Data Cleaning | Hackathon Project**

SaaSsum AI is an AI-assisted spreadsheet cleaning solution that transforms messy Excel and CSV files into clean, structured, and analysis-ready datasets. It helps users reduce manual work, improve data quality, and prepare reliable data for reporting and analysis.

## 📌 Problem Statement

Excel and CSV files often contain duplicate records, missing values, inconsistent formats, and incorrect entries. Manually cleaning these datasets is time-consuming, repetitive, and prone to human error.

SaaSsum AI aims to automate this process through a simple, user-friendly interface.

## 💡 Our Solution

SaaSsum AI allows users to upload spreadsheet files, identify data quality issues, apply cleaning operations, and download the cleaned dataset.

## ✨ Core Features

- 📂 **File Upload:** Upload Excel and CSV files for processing.
- 🧹 **Automatic Data Cleaning:** Identify missing values, inconsistent formats, and duplicate records.
- 🔄 **Data Standardization:** Normalize column names, text values, and data formats.
- 📊 **Data Preview:** Review the dataset and understand detected issues before and after cleaning.
- 📥 **Export Cleaned Data:** Download the processed dataset for further analysis.

## 🛠️ Technology Stack

- **Frontend:** Web-based user interface
- **Backend:** Python
- **Data Processing:** Pandas, OpenPyXL
- **Similarity Matching:** RapidFuzz
- **Supported Formats:** Excel (.xlsx) and CSV (.csv)

## ⚙️ How It Works

1. Upload an Excel or CSV file.
2. The system analyzes the dataset.
3. Detect duplicates, missing values, and inconsistent data.
4. Apply the required cleaning and standardization operations.
5. Preview the cleaned dataset.
6. Download the final file.

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or later
- pip package manager
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/rohitvenni19-cloud/saassum-ai-hackathon.git
```

Navigate to the project directory:

```bash
cd saassum-ai-hackathon
```

Install dependencies if a `requirements.txt` file exists:

```bash
pip install -r requirements.txt
```

Run the application using the command appropriate for your project framework. For example, if your application uses Streamlit:

```bash
streamlit run app.py
```

If you use Flask, FastAPI, or another framework, replace this command with the appropriate startup command.
